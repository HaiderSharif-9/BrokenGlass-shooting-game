🎯 Broken Glass – Shooting Gallery

A browser-based shooting game built entirely in a single HTML file using HTML5, CSS3, and Vanilla JavaScript.

🎮 About

Broken Glass is a fast-paced arcade shooting game where players destroy bottles, cans, and other targets while managing health, bullets, combos, and increasing difficulty. The game runs directly in any modern web browser with no installation required.

✨ Features

- 🎯 Smooth shooting gameplay
- 🥤 Multiple target types (Bottles, Cans, Hearts & Bombs)
- ❤️ Health and bullet management
- 🔥 Combo scoring system
- 📈 Progressive levels with increasing difficulty
- 🌦️ Dynamic backgrounds and weather effects
- 🔊 Built-in sound effects
- 🏆 Personal leaderboard and game statistics
- ⚙️ Difficulty settings
- 📱 Responsive design for desktop and mobile
- 💾 Progress saved using LocalStorage

🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Canvas API
- Web Audio API
- LocalStorage

🚀 How to Run

1. Download or clone this repository.
2. Open BrokenGlass Game.html in any modern web browser.
3. Click Start Game and enjoy!

No installation or external dependencies are required.
